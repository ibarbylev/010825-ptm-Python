### 1. Необходимо реализовать поиск фильмов (MySQL)

1. По ключевому слову 
   * Поиск по названию фильма   
   * Результат ограничен 10 фильмами
   * По запросу пользователя отображаются следующие 10 результатов, или пока не закончатся


2. По жанру и диапазону годов выпуска
   * Перед вводом пользователю показываются:
     * Список всех жанров из таблицы жанров 
     * Минимальный и максимальный год выпуска фильмов в базе
   * Указывается нижняя и верхняя граница, например: от 2005 до 2012, или конкретный год
   * По запросу пользователя отображаются следующие 10 результатов, или пока не закончатся


### 2. Сохранение запросов (MongoDB)

Сохранять все поисковые запросы в MongoDB в коллекцию `final_project_<your_group>_<your_full_name>`.

```json
[
    {
        "timestamp": "2025-05-01T15:34:00",
        "search_type": "keyword",
        "params": {
            "keyword": "matrix"
        },
        "results_count": 3
   },
    {
        "timestamp": "2025-05-01T15:35:00",
        "search_type": "genre__years_range",
        "params": {
            "genre": "Action",
            "years_range": "2001-2010"
        },
        "results_count": 5
   }
]
```

### 3. Отображение статистики запросов

Выводить список из 5 популярных запросов на выбор пользователя:
* по частоте (самые популярные по убыванию частоты)
* по последним поискам (5 последних уникальных запросов по убыванию от новых к старым).
* Каждый запрос включает в себя:
  * тип запроса `search_type`: 
    * `keyword` or 
    * `genre__years_range`
  * параметры запроса `params`
  * количество строк в выборке `results_count`
  * время запроса `timestamp`


### 4. Технологии

1. Python
2. MySQL
3. MongoDB


### 5. Дополнительные требования (обязательные)

1. **Соблюдение правил PEP8**
   * Код оформлен согласно стандартам **PEP8** (отступы, пробелы, длина строк, имена переменных). 
   * Используются понятные имена переменных и функций.


2. **Читабельность кода**
   * Каждая функция выполняет одну понятную задачу, без лишней вложенности и дублирования.
   * Присутствуют комментарии там, где это необходимо (например, описание логики запроса).


3. **Разделение проекта на функции и модули**
